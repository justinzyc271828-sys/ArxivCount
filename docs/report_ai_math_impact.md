# 研究报告：arXiv 数学领域 AI 辅助证明的可观测冲击（本地 proxy）

**作者**：Justin Yao  
**项目**：ArxivCount  
**生成数据截止**：2026-08（本地抓取）  
**状态**：基于全文 + 贡献分级的内部报告草案（非期刊投稿）

---

## 0. 一句话结论

在 arXiv `math.*` 的**可观测、自我披露**样本中，AI 对数学的冲击呈现清晰两阶段：

1. **2023–2024**：工具与评测建设期（几乎没有 C3/C4 级「实质数学贡献」）；  
2. **2025–2026**：研究级进入 → **开放问题波**，严格贡献集（C3+）从 2025 的 27 跳到 2026 的 94。

人仍是主验证与主叙事者；但 AI 已从「写摘要/改英语」进入「构造反例、起草证明、形式化、规模化搜索」的实质环节。

---

## 1. 研究问题

1. AI 在数学中**真正做了什么**（能力类型）？  
2. 哪些是**脏数据/噪音**，哪些是**辅助**，哪些是**实质贡献**？  
3. 何时进入「证明层」？有哪些**里程碑**推动？  
4. 如何用**宽/严双轨**讲清楚，避免夸大或低估？

## 2. 方法与精度定义

### 2.1 流水线

```text
seed 抓取 (math.* + AI/Lean/formal 关键词)
  → 宽松候选 (~1206)
  → 规则 + DeepSeek 精筛 (~228)
  → 全文 PDF/HTML + DeepSeek 复核 (226)
  → 贡献分级 C0–C4 (226)
  → 时间轴 / 宽严集合 / 仪表盘
```

### 2.2 贡献层级（核心精度定义）

| 层级 | 名称 | 含义 | 是否进宽集 | 是否进严格集 |
|------|------|------|------------|--------------|
| **C0** | 噪音 | 假阳性 / 非 AI-for-math | 否 | 否 |
| **C1** | 外围 | 仅润色、排版、无关代码 | 否 | 否 |
| **C2** | 辅助 | 有帮助但非决定主结果 | 是 | 否 |
| **C3** | 实质贡献 | 关键引理/反例/构造/形式化 | 是 | 是 |
| **C4** | 决定性/里程碑 | 命名开放问题或高可见突破写本 | 是 | 是 |

详见 `config/contribution_taxonomy.yaml`。

### 2.3 边界（必须写进任何对外文）

- 样本 = seed 可观测宇宙，**不是**全部 math 论文普查。  
- 依赖作者披露；未写 AI 的真实使用不可见。  
- 全文为 PDF 抽取头尾，非人工通读。  
- C3/C4 由模型分级，需人工抽检校准。

## 3. 主要数据结果（当前本地跑数）

### 3.1 漏斗

| 阶段 | 约数 |
|------|------|
| unique 入库 | ~1897 |
| 宽松命中 | ~1206 |
| 摘要/规则精筛 | ~228 |
| 全文确认 | **226** |
| 宽集 C2+ | **219** |
| 严格集 C3+ | **121** |
| C4 或 milestone 候选 | **~61** |

### 3.2 层级分布

| Tier | n |
|------|---|
| C4 | 59 |
| C3 | 62 |
| C2 | 98 |
| C1 | 7 |
| C0 | 0 |

解读：进入全文确认后，**脏数据已被大幅滤掉**；剩余争议主要在 C2 vs C3（辅助 vs 实质）。

### 3.3 时间结构（关键发现）

**宽集（生态）逐年：**

| 年 | wide |
|----|------|
| 2022 | 1 |
| 2023 | 10 |
| 2024 | 14 |
| 2025 | 55 |
| 2026 | 139 |

**严格集（实质数学贡献主张）：**

| 年 | strict (C3+) |
|----|----------------|
| ≤2024 | **0**（本样本） |
| 2025 | **27** |
| 2026 | **94** |

这是对外叙事最硬的一张表：  
**「证明层」不是从 ChatGPT 发布日开始的，而是 2025 起量、2026 成波。**

### 3.3b 分母与渗透率（math 全量）

分母：arXiv API `cat:math*` 按自然年的 `opensearch:totalResults`（脚本 `python -m src.denominator`）。

| 年 | math_total | wide | strict | wide/10k | **strict/10k** | strict % |
|----|------------|------|--------|----------|----------------|----------|
| 2022 | 42363 | 1 | 0 | 0.24 | 0 | 0 |
| 2023 | 44876 | 10 | 0 | 2.23 | 0 | 0 |
| 2024 | 48751 | 14 | 0 | 2.87 | 0 | 0 |
| 2025 | 52417 | 55 | 27 | 10.5 | **5.15** | 0.052% |
| 2026* | 37861 | 139 | 94 | 36.7 | **24.8** | 0.25% |

\*2026 为不完全年（抓取截止约 8 月初），math_total 与计数均会继续涨；**水平不可直接与全年年份比**，应看年内轨迹与 per-10k 量级。

**计量解读（冷静）：**

1. 即便在 2026 样本窗口，严格集也仅约 **万分之二十五** 量级（且分子是 seed 披露 proxy，真实披露渗透仍是下界问题）。  
2. 从 2025 到 2026 窗口，strict/10k 从 ~5 跳到 ~25，**相对加速**比绝对渗透更值得写。  
3. 因此对外句式应为：「结构转折清晰，基数仍极薄。」

### 3.4 能力画像（多标签）

出现较多的能力（节选）：

- method_or_benchmark_only  
- full_proof_draft  
- verification_bugfinding  
- code_generation  
- large_scale_search_evolution  
- counterexample_construction  
- conjecture_proposal  
- formal_proof_search / autoformalization  

解读：生态里仍有大量「造工具」；但 **proof draft / counterexample / search** 已足够支撑「冲击」叙事。

### 3.5 领域分工（与全文审计一致）

- **组合 / 数论 / 部分分析**：更易出现 C3/C4 证明与反例  
- **优化 / 理论 CS 邻域**：更多方法系统（C2 为主，偶有 C3）  
- **Lean 形式化**：上升中，仍非主流路径

## 4. 时间轴与里程碑（五阶段）

| 阶段 | 时间 | 特征 |
|------|------|------|
| Prehistory | ~2015–2022.10 | 形式化/CAS；几乎无 LLM 证明叙事 |
| Mass LLM | 2022.11–2023 | ChatGPT/GPT-4；写作与演示 |
| Olympiad & formal | 2024 | AlphaGeometry / AlphaProof |
| Research entry | 2025 | 严格贡献开始出现（本样本 27） |
| Open-problem wave | 2026 | 严格贡献暴增（本样本 94）；Erdős / unit distance 等锚点 |

Canon 里程碑见 `config/milestones.yaml`；展开时间轴见 `docs/timeline.md`。

**个人判断（可写进长文，需标明是判断）：**

1. 2024 解决的是「AI 能否在竞赛/形式系统里像数学学生」；  
2. 2025–2026 才开始认真回答「AI 能否推动研究级开放问题」；  
3. unit distance / Erdős 系列的意义，主要是**改变社区预期**，而不只是单点结果。

## 5. 推演与判断（讨论版）

### 5.1 AI 大概能做哪些事（按证据强度）

| 能力 | 证据强度 | 说明 |
|------|----------|------|
| 润色与写作 | 高 | 常见但应剔除出严格集 |
| 代码/数值实验 | 高 | 传统计算机辅助的延伸 |
| 反例/构造搜索 | 中高 | 2025–26 开放问题里很显眼 |
| 证明草稿 | 中高 | 常需人重写与验证 |
| Lean 形式化/证明搜索 | 中 | 增长快，仍偏少 |
| 完全自主研究 | 低 | 样本中仍罕见；多是 human-led |

### 5.2 冲击的本质

不是「数学家失业」，而是：

- **搜索半径扩大**（反例、构造、证明草图）  
- **验证路径变化**（Lean / 人机共验）  
- **问题选择变化**（更敢碰长期开放问题）  
- **发表与披露规范尚未稳定**（造成观测偏差）

### 5.3 风险

- 把 C2 系统文算进「证明爆炸」→ 夸大  
- 只看 C4 → 低估生态基础设施建设  
- 忽略未披露 AI 使用 → 低估真实渗透  

**建议对外永远双轨：宽集讲生态，严格集讲冲击。**
